

##  先用一个比喻讲清楚：REST API 就是「餐厅点餐窗口」

想象 Salesforce 是一座大型餐厅。

* **普通 Apex 类** = 厨房里的厨师
* **Trigger** = 顾客动作触发厨房自动处理
* **Batch** = 厨房的深夜批量备菜
* **REST API** = 餐厅的 **对外点餐窗口**

别人（外部系统）不用进厨房，也不用知道厨师是谁，只要说：

> 你给我来一个“返回账户信息”的套餐。

Salesforce 就会根据你设计的 API 接口，把数据“打包”并“送出去”。

要在 Salesforce 中创建自己的“点餐窗口”，就要用 **Apex REST API**。

# 🔥 Part 1：自定义 REST API 的结构

## 🧩 Apex REST API 的三个关键要素

| 要素                                      | 比喻                    | 在 API 中的作用         |
| --------------------------------------- | --------------------- | ------------------ |
| `@RestResource(urlMapping='/xxx/*')`    | 决定餐厅窗口位置              | 客户端访问的 URL         |
| `@HttpGet / @HttpPost / @HttpPatch ...` | 顾客点菜方式（堂食 / 外带 / 订外卖） | 定义 API 使用的 HTTP 方法 |
| 返回格式（JSON）                              | 最终上的菜                 | 系统返回的数据            |

# 🔧 Part 2：最简单的一个自定义 REST API 示例

## 🍱 示例：通过 REST API 获取 Account 信息

### 📌 类比

**你开了一个窗口：`/services/apexrest/AccountAPI/info`**
顾客（外部程序）说：“给我 id = xxx 的账户信息”。

厨房（Apex 代码）查好返回 JSON。

---

### 🧑‍💻 代码示例

```apex
@RestResource(urlMapping='/AccountAPI/*')
global with sharing class AccountRestAPI {

    @HttpGet
    global static Account getAccountInfo() {
        // 从 URL 中取参数，例如：?id=0015g00000xxx
        RestRequest req = RestContext.request;
        String accId = req.params.get('id');

        return [SELECT Id, Name, Industry FROM Account WHERE Id = :accId LIMIT 1];
    }
}
```

# 🚀 Part 3：讲讲自定义 REST API 常用注解

## 1️⃣ @RestResource

像是在“餐厅外墙贴上招牌，告诉人们窗口在哪里”。

```apex
@RestResource(urlMapping='/MyAPI/*')
```

定义了外部访问路径：

```
/services/apexrest/MyAPI/xxx
```

---

## 2️⃣ @HttpGet —— 查东西用

像“顾客来询问一下菜单内容”，不会修改数据。

```apex
@HttpGet
```

适合做：

* 查询记录（Account、Contact）
* 返回统计结果
* 获取设定值

---

## 3️⃣ @HttpPost —— 新建数据用

像“顾客点菜并把订单提交给你”。

```apex
@HttpPost
```

适合做：

* 创建记录
* 执行某些逻辑流程

---

## 4️⃣ @HttpPatch / @HttpPut —— 更新数据

像“修改订单”。

```apex
@HttpPatch
@HttpPut
```

---

## 5️⃣ @HttpDelete —— 删除数据

像“取消订单”。

```apex
@HttpDelete
```

# 🍜 Part 4：接收 JSON、返回 JSON（最常用的技能）

## 🔥 示例：POST 一个订单，让 API 创建 Account

### 📌 请求示例（外部系统发送）

```json
{
  "name": "Tokyo Bikes",
  "phone": "03-0000-0000"
}
```

---

### 🧑‍💻 Apex API 接收 JSON 并创建记录

```apex
@RestResource(urlMapping='/AccountAPI/*')
global with sharing class AccountRestAPI {

    @HttpPost
    global static Id createAccount() {

        RestRequest req = RestContext.request;

        // 将 JSON 转换为 Apex 对象
        Map<String, Object> jsonBody = (Map<String, Object>) JSON.deserializeUntyped(req.requestBody.toString());

        Account acc = new Account();
        acc.Name = (String)jsonBody.get('name');
        acc.Phone = (String)jsonBody.get('phone');

        insert acc;

        return acc.Id;
    }
}
```

💡 **`JSON.deserializeUntyped`** 是 Salesforce 最常用的 JSON 解析方式（适合 API）。

# 🍣 Part 5：返回自定义 JSON（不直接返回 sObject）

例如你希望返回：

```json
{
  "status": "success",
  "accountId": "001xxx",
  "message": "客户创建成功"
}
```

### 📌 示例代码

```apex
@RestResource(urlMapping='/AccountAPI/*')
global with sharing class AccountRestAPI {

    @HttpPost
    global static String createAccount() {
        RestRequest req = RestContext.request;
        Map<String, Object> body = (Map<String, Object>) JSON.deserializeUntyped(req.requestBody.toString());

        Account acc = new Account(Name=(String)body.get('name'));
        insert acc;

        Map<String, Object> result = new Map<String, Object>();
        result.put('status', 'success');
        result.put('accountId', acc.Id);
        result.put('message', '客户创建成功');

        return JSON.serialize(result);
    }
}
```

# 🛑 Part 6：自定义 REST API 必须知道的注意事项（非常重要）

## ✔ 1. 全局类必须 `global`

否则外部系统无法访问。

## ✔ 2. 需要 with sharing / without sharing

外部访问数据时要遵守权限吗？

* **with sharing** → 遵守系统权限
* **without sharing** → 不遵守（常用于集成）

## ✔ 3. 不支持 sessionId，只能用 OAuth 等授权方式

## ✔ 4. Trigger 不会自动在 API 中触发？

**错误！会触发。**
API → DML → Trigger → Flow → Validation 都一样执行。

## ✔ 5. 要记得避免 SOQL 过量（Governor Limit）

# 🛰️ **附录：SAP ABAP 调用 Salesforce Apex REST API 的例子**

## 先用比喻讲一下

把 ABAP 想成另一家餐厅，它要来你 Salesforce 餐厅点餐。

* Salesforce 的 Apex REST API = **点餐窗口**
* ABAP = **外卖骑手**
* ABAP 使用 HTTP 客户端调用 Salesforce 的 REST API 并带上「身份证」(token) 才能成功访问。

---

# 🎯 调用目标：

我们要从 ABAP 调用你上面写的 Apex REST API，比如：

```
/services/apexrest/AccountAPI/info?id=00100001ABC...
```

---

# 🔑 第一步：准备 Salesforce 端

假设你的 Apex API：

```apex
@RestResource(urlMapping='/AccountAPI/*')
global with sharing class AccountRestAPI {

    @HttpGet
    global static Account getAccountInfo() {
        RestRequest req = RestContext.request;
        String accId = req.params.get('id');

        return [
            SELECT Id, Name, Industry 
            FROM Account 
            WHERE Id = :accId 
            LIMIT 1
        ];
    }
}
```

访问路径（Production）：

```
https://yourInstance.salesforce.com/services/apexrest/AccountAPI/info?id=XXXX
```

---

# 🔐 第二步：在 SAP ABAP 中获取 Salesforce OAuth Token（最常见方式）

ABAP 调用 Salesforce 的 REST API，常见步骤是：

1. 先用 **Connected App** 发起 OAuth 2.0 token 请求
2. 从响应中拿到 `access_token`
3. 再用 token 调你的 Apex REST API

---

# 🧑‍💻 **ABAP 代码：获取 Salesforce token（OAuth2 Client Credentials / Username-Password Flow）**

（示例使用 Username-Password Flow，ABAP 最常用）

```abap
DATA: lo_http_client TYPE REF TO if_http_client,
      lv_url         TYPE string,
      lv_body        TYPE string,
      lv_response    TYPE string,
      json_token     TYPE string,
      lv_token       TYPE string.

lv_url = 'https://login.salesforce.com/services/oauth2/token'.

" Salesforce OAuth 请求体
lv_body = |grant_type=password&client_id={your_client_id}&client_secret={your_client_secret}&username={your_username}&password={your_password_with_security_token}|.

CALL FUNCTION 'HTTP_CLIENT_CREATE'
  EXPORTING
    host = 'login.salesforce.com'
    service = '443'
    ssl_id = 'ANONYM'
  IMPORTING
    client = lo_http_client.

lo_http_client->request->set_method( 'POST' ).
lo_http_client->request->set_header_field( name = 'Content-Type' value = 'application/x-www-form-urlencoded' ).
lo_http_client->request->set_cdata( lv_body ).

CALL METHOD lo_http_client->send.
CALL METHOD lo_http_client->receive.

lv_response = lo_http_client->response->get_cdata( ).

" 解析 JSON，获取 access_token
CALL FUNCTION 'ECATT_CONV_JSON_TO_ABAP'
  EXPORTING
    json = lv_response
  IMPORTING
    abap = json_token.

lv_token = json_token-access_token.
```

结果 `lv_token` 就是你后续调用 Apex API 的通行证。

---

# 🚀 第三步：ABAP 调用你写好的 Apex REST API

```abap
DATA: lo_http_client2 TYPE REF TO if_http_client,
      lv_api_url      TYPE string,
      lv_result       TYPE string.

" Apex 自定义 API URL
lv_api_url = 'https://yourInstance.salesforce.com/services/apexrest/AccountAPI/info?id=00100000ABC123'.

CALL FUNCTION 'HTTP_CLIENT_CREATE'
  EXPORTING
    host = 'yourInstance.salesforce.com'
    service = '443'
    ssl_id = 'ANONYM'
  IMPORTING
    client = lo_http_client2.

lo_http_client2->request->set_method( 'GET' ).
lo_http_client2->request->set_header_field( name = 'Authorization' value = |Bearer { lv_token }| ).
lo_http_client2->request->set_header_field( name = 'Content-Type' value = 'application/json' ).

CALL METHOD lo_http_client2->send.
CALL METHOD lo_http_client2->receive.

lv_result = lo_http_client2->response->get_cdata( ).
```

`lv_result` 会像这样：

```json
{
  "Id": "00100000ABC123",
  "Name": "Tokyo Bikes",
  "Industry": "Manufacturing"
}
```
