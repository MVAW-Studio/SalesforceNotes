


## 🕐 1. Date 类


### 常用方法

| 方法                           | 作用          | 返回值类型     |
| ---------------------------- | ----------- | --------- |
| `Date.today()`               | 取得今天的日期     | `Date`    |
| `Date.new(year, month, day)` | 创建指定日期      | `Date`    |
| `addDays(n)`                 | 当前日期加上n天    | `Date`    |
| `addMonths(n)`               | 当前日期加上n个月   | `Date`    |
| `addYears(n)`                | 当前日期加上n年    | `Date`    |
| `daysBetween(date2)`         | 计算两个日期之间的天数 | `Integer` |
| `isLeapYear(year)`           | 判断闰年        | `Boolean` |

### 🌰 示例

```apex
Date today = Date.today(); // 今天的日期
Date birthday = Date.new(1995, 5, 10); // 1995年5月10日
Date nextWeek = today.addDays(7); // 一周后
Integer diff = today.daysBetween(birthday); // 相差的天数
Boolean leap = Date.isLeapYear(2024); // 是否闰年？
System.debug('今天：' + today + ' 一周后：' + nextWeek);
System.debug('距离生日天数：' + diff);
System.debug('2024是闰年吗？' + leap);
```

## ⏰ 2. Datetime 类


### 常用方法

| 方法                                                       | 作用      | 返回值        |
| -------------------------------------------------------- | ------- | ---------- |
| `Datetime.now()`                                         | 当前日期和时间 | `Datetime` |
| `Datetime.newInstance(year, month, day, hour, min, sec)` | 创建指定时间  | `Datetime` |
| `addDays(n)` / `addHours(n)` / `addMinutes(n)`           | 时间加减    | `Datetime` |
| `format()`                                               | 按区域格式化  | `String`   |
| `date()`                                                 | 取出日期部分  | `Date`     |
| `time()`                                                 | 取出时间部分  | `Time`     |

### 🌰 示例

```apex
Datetime now = Datetime.now();
Datetime meeting = Datetime.newInstance(2025, 12, 1, 14, 30, 0);
Datetime later = now.addHours(3);
System.debug('现在：' + now.format());
System.debug('会议时间：' + meeting);
System.debug('三小时后：' + later);
```
